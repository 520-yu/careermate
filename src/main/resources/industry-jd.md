# 行业 JD 知识库

> 用途：JD 匹配时用目标 JD 去检索相似岗位，据此判断「这个岗位实际看重什么」。
> 格式与 `interview-questions.md` 完全一致，由同一个加载器解析；
> 元数据里的 `source` 字段用于把两类知识与面试题库区分开。

### [行业JD][中级] Java 后端工程师（互联网业务研发）
岗位职责：负责核心业务系统的服务端设计与开发，支撑高并发交易链路。
任职要求：
- 本科及以上，3 年左右 Java 后端经验；
- 精通 Java 基础、集合、并发与 JVM 调优，能定位线上性能问题；
- 熟练使用 Spring Boot / Spring Cloud，理解自动配置与 AOP 原理；
- 熟悉 MySQL 索引优化与事务隔离，有慢 SQL 治理经验；
- 熟悉 Redis 缓存设计与常见缓存问题（穿透/击穿/雪崩）；
- 了解消息队列（RocketMQ / Kafka）的使用与幂等设计；
- 有分布式系统经验、熟悉 DDD 者优先。

### [行业JD][高级] 资深 Java 后端工程师（架构方向）
岗位职责：负责交易中台的架构演进、技术选型与稳定性治理。
任职要求：
- 5 年以上 Java 服务端经验，主导过至少一个中大型系统的架构设计；
- 深入理解分布式一致性、幂等、最终一致性与补偿事务；
- 有高并发场景实战经验，能独立完成容量评估与压测方案；
- 熟悉 JVM 底层与 GC 调优，有线上故障排查与复盘经验；
- 熟悉微服务治理（限流、熔断、降级、链路追踪）；
- 有技术方案评审与技术分享习惯。

### [行业JD][中级] AI 应用开发工程师（大模型方向）
岗位职责：负责基于大模型的业务应用落地，包括知识库问答、Agent 编排与效果优化。
任职要求：
- 有 Java / Python 至少一门语言的工程能力，熟悉 Spring Boot；
- 理解 RAG 完整链路：文档切分、Embedding、向量检索、上下文拼装；
- 有向量数据库（Qdrant / Milvus / PGVector）使用经验；
- 熟悉 Prompt 工程与结构化输出（JSON Schema 约束）实践；
- 了解 Function Calling / Tool 调用机制，能做多步 Agent 编排；
- 有模型效果评测与迭代经验者优先。

### [行业JD][初级] Java 后端开发工程师（应届 / 1 年）
岗位职责：参与业务功能开发，编写接口与单元测试。
任职要求：
- 计算机相关专业本科及以上；
- 掌握 Java 基础语法、面向对象与常用集合；
- 了解 Spring Boot 基本用法，能独立完成 CRUD 接口；
- 会写基本 SQL，了解索引概念；
- 有课程设计或实习项目经历，能讲清自己负责的部分；
- 学习能力强，愿意阅读源码。

### [行业JD][中级] 大数据开发工程师（数据平台）
岗位职责：负责离线与实时数据链路开发，支撑业务指标与报表。
任职要求：
- 熟悉 Hadoop / Spark / Flink 至少一种计算引擎；
- 熟练编写 SQL，有海量数据下的性能调优经验；
- 熟悉 Kafka 等消息中间件与数据同步工具；
- 了解数据仓库分层建模（ODS / DWD / DWS / ADS）；
- 有 Java 或 Scala 开发能力。

### [行业JD][中级] 全栈开发工程师（中小型团队）
岗位职责：独立负责一个业务模块的前后端实现与上线。
任职要求：
- 熟悉 Java 后端与至少一种前端框架（Vue / React）；
- 能独立完成需求拆解、接口设计与联调；
- 熟悉 Linux 常用命令与基本部署（Docker）；
- 有从 0 到 1 交付项目的经验；
- 沟通能力强，能在需求不明确时主动澄清。

### [行业JD][高级] 技术负责人 / 后端 Team Leader
岗位职责：带领 3-8 人团队交付业务，负责技术规划与人员成长。
任职要求：
- 扎实的后端技术功底，能进行代码评审与技术攻坚；
- 有团队管理与跨部门协作经验；
- 能拆解复杂需求、制定排期并控制风险；
- 有稳定性建设与故障应急处理经验；
- 具备技术选型与方案输出的书面表达能力。

### [行业JD][中级] 中间件 / 基础架构工程师
岗位职责：负责公司级中间件（消息队列、缓存、配置中心）的建设与运维。
任职要求：
- 熟悉 RocketMQ / Kafka 的原理与运维，能排查消息堆积与重复消费；
- 熟悉 Redis 集群方案与容量规划；
- 有源码级阅读经验，能基于开源组件做二次开发；
- 熟悉容器化与 Kubernetes 基本使用；
- 具备较强的线上问题定位能力。
